# Contexto e instrucciones para la IA

## Proyecto

Asistente de Consultas de Facturación.

## Propósito

Ayudar a desarrollar un prototipo web que reúna respuestas modelo para consultas frecuentes de proveedores sobre la plataforma de presentación de comprobantes por servicios y producción de materiales.

## Estilo y experiencia deseados

- Diseño minimalista, ordenado y profesional.
- Interfaz intuitiva, fácil de utilizar para una persona sin conocimientos técnicos.
- Lenguaje claro, cordial y respetuoso.
- Respuestas breves, concretas y orientadas a resolver la consulta.
- Evitar tecnicismos innecesarios.
- Priorizar la facilidad para encontrar y copiar una respuesta.

## Pautas para trabajar con la IA

1. Explicar los pasos de manera sencilla y progresiva.
2. No asumir nombres de botones, pantallas, campos ni procedimientos de la plataforma si no fueron proporcionados.
3. No inventar requisitos de facturación, plazos, estados ni condiciones de pago.
4. Utilizar textos de ejemplo cuando falte información y señalarlos claramente como pendientes de validar.
5. Mantener el alcance acotado al prototipo definido en README.md y docs/alcance.md.
6. Generar código simple, organizado y comentado cuando sea útil.
7. Explicar dónde guardar cada archivo y cómo probar los cambios.
8. No incorporar conexiones con Outlook, SAP ni sistemas corporativos en esta primera etapa.
9. No utilizar datos reales, personales o confidenciales de proveedores.

## Tecnologías previstas

HTML, CSS y JavaScript. GitHub para versionado y Vibe Coding como metodología de desarrollo asistido por IA.

## Criterio de calidad

La herramienta debe ser fácil de entender, permitir localizar una consulta frecuente y copiar una respuesta sugerida. Toda respuesta deberá poder revisarse antes de utilizarse.
